# standards-naming

Naming conventions for all files, components, hooks, services, and mock variables.

## Conventions

| Thing | Convention | Example |
|-------|-----------|---------|
| Files / folders | `kebab-case` | `delivery-listing.tsx` |
| Components | `PascalCase` | `DeliveryListing` |
| Types / Interfaces | `PascalCase` | `DeliveryItem` |
| Hooks | `useCamelCase` | `useDeliveryListing` |
| Services | `camelCase` | `deliveryService.ts` |
| Mock variables | `mock<PageName>Items` | `mockDeliveryItems` |
